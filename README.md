# 실시간 근접 객체 경고

브라우저 카메라 영상에서 객체를 탐지하고, 깊이 추정 모델로 거리를 계산해 가까운 객체를 화면과 한국어 음성으로 알려주는 Streamlit 앱입니다.

## 주요 기능

- 브라우저 웹캠을 이용한 실시간 영상 분석
- YOLO 객체 탐지 및 깊이 추정
- 기본 경고 거리 2m (화면에서 0.5~5m로 조절 가능)
- 경고 거리 안의 객체 중 화면에서 가장 큰 객체의 이름, 신뢰도, 추정 거리 표시
- FPS 표시 및 브라우저 한국어 음성 경고

## 필요한 파일

다음 파일을 앱과 같은 디렉터리에 둡니다.

```text
app.py2
requirements2.txt
yolo11n.pt
yolo26n-depth.pt
```

모델 파일은 앱에서 자동으로 다운로드하지 않습니다. 배포할 때도 두 `.pt` 파일을 함께 업로드해야 합니다.

## 로컬 실행

Python 환경을 준비한 다음 프로젝트 디렉터리에서 의존성을 설치하고 앱을 실행합니다.

```powershell
python -m pip install -r requirements2.txt
streamlit run app.py2
```

브라우저에서 앱이 열리면 **카메라 분석 활성화**를 켜고, WebRTC 화면의 시작 버튼을 누른 뒤 카메라 접근을 허용합니다. 경고 거리는 슬라이더에서 조절할 수 있습니다.

## 웹 배포 시 참고

- 브라우저 카메라 접근에는 HTTPS가 필요합니다. `localhost`에서는 보통 HTTP로도 테스트할 수 있습니다.
- 배포 서버에 `yolo11n.pt`와 `yolo26n-depth.pt`를 포함해야 합니다.
- `requirements2.txt`를 의존성 파일로 지정합니다. 배포 플랫폼이 `requirements.txt`만 자동 인식하면 플랫폼 설정에서 파일을 지정하거나, 기존 `requirements.txt`를 백업한 뒤 이 파일의 의존성을 반영해야 합니다.
- 영상 추론은 배포 서버에서 실행됩니다. 서버 CPU/GPU 성능과 네트워크 환경에 따라 FPS 및 WebRTC 연결 품질이 달라질 수 있습니다.
- 음성 출력은 브라우저의 한국어 음성 합성 기능을 사용합니다. 브라우저가 음성 합성을 지원하지 않으면 음성 경고를 들을 수 없습니다.

## 분석 방식

객체 탐지는 `yolo11n.pt`, 거리 추정은 `yolo26n-depth.pt`를 사용합니다. 객체 상자 중앙 영역의 유효한 깊이값 중앙값을 거리로 사용하고, 경고 거리 이내 객체 중 상자 면적이 가장 큰 객체를 경고 대상으로 선택합니다.
